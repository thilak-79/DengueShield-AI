# DengueShield AI

An explainable AI-powered dengue forecasting and intelligence platform for Sri Lanka.

## Main Components

- Dengue surveillance data pipeline
- Weather data integration
- Machine learning forecasting
- Explainable AI using SHAP
- FastAPI backend
- React dashboard
- Sri Lanka interactive map
- Multilingual RAG assistant
- Computer vision breeding-habitat detection
